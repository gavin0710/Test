## 1. 目标与页面取舍
做一套可量化、可追随、能通过真实历史检验的指数技术交易辅助系统，**不是学术研究，也不代表已经验证有盈利优势**。关注四大指数：上证指数、深证成指、创业板指、科创50；六周期：15/60/90/120分钟、日线、周线。四张K线同时显示，MACD(12,26,9)与九转辅助观察；支持K线密度调节、拖动全历史、关键点位定位、结构交易统计和四图历史回放。页面应优先服务交易判断：**K线是主角，少解释、少重复、不加无意义模块**。不要自行扩充纠错方案、复盘标签、笔记和波浪成功率；波浪分组有效性尚未验证。

## 2. 已确定的交易规则
- **钝化**：比较最近两个相邻同色MACD柱区，两区之间至少3根连续非同色柱；底部第二同色区的最低**收盘价**创新低但DIF低点不创新低，顶部对称。只用已完成K线；影线不参与，不能跳过最近同色区。
- **买卖点**：底钝化后DIF首次上拐为买1，顶钝化后首次下拐为卖1；同结构后续再次拐头记买2/3或卖2/3。
- **结构仓位账本**：每个新底部买1建立独立风险单元，结构ID `B:<K线序号>`；同结构买2/3只补充信号，不另建单元；不同底部结构的风险独立。有效期内DIF跌破所属底部参考低点，只止损**本结构**；结构因连续3根反色柱或被新结构取代而结束后，旧止损线不重新激活，仍持有单元等待顶部卖点。一个顶部卖点可同时退出多个独立单元，卖点信号数不等于退出交易笔数。
- **纠错买回**：已实际配对顶部卖出后，在有效期内DIF严格上破前红柱参考DIF高点H，产生纠错买回；买回继承原结构ID，可能一次信号对应多个结构单元。从下一根已完成K线起，DIF≤H即按各单元执行纠错止损；当根不能重复退出。该“止损”是DIF条件退出，**不等于价格必然亏损**。
- **双统计口径**：必须区分**市场信号次数**与**独立风险单元交易段数量**；点位导航/历史事件按触发去重，逐笔收益和退出明细按单元保留；同一根K线多单元退出不能算多个独立市场机会。

## 4. 本轮新增页面要求：推演只在重点观察期出现
- **只在当前最新K线、正式看盘模式、已确认钝化仍处于观察状态时显示“下一根K线推演”**：`projection.mode === "watch"`（钝化已成立、待首次DIF拐头），或 `"campaign"`（已形成买/卖1，原结构仍有效、等待后续拐头）。
- 普通无信号、尚未确认的`candidate`、失效`invalid`、已确认但非有效观察期的`signal`、纠错待买回/持有状态均**不显示推演卡片及预测价虚线**；历史拖动和逐笔复盘也不显示占空间的提示占位。买卖、纠错和风控**计算逻辑及历史事件不删除**。
- 该项属于**展示收敛**，不是改变既定信号触发条件或退出规则。后续不要再把“暂无推演”“历史仅最新推演”等说明反复摆在四张图底部。

1. **实际可交易性与系统有效性**：固定本轮执行假设，用对应ETF扩到其余三个指数日线；逐段做滚动和样本外验证，增加匹配资金暴露的基准，并以公开逐笔或开盘竞价数据校验成交假设。分钟线目前仅31个交易日，先补有效样本覆盖，验证股票ETF当日买入后的T+1约束。
2. **纠错方案独立评价**：按独立纠错市场信号统计，不把22单元当22个独立样本；对比按DIF参考线退出与其他退出规则的表现，避免事后选择最优参数。
3. **四指共振有效性**：复盘当前按同周期触发时点及此前2根已完成K线统计，不看未来。还需在真实数据上检验共振强弱是否改善后续表现；不要先写有利结论。
4. **行情覆盖、时效和边界规则**：核验下一交易日的自动采集，接手时只查到采集工作流的推送触发记录。继续检查分钟缺口前后连续性、同周多时间戳、节假日提前结束的周线，以及 README 中纠错止损与同根顶部卖点的归因顺序。本轮24组历史未发现后者同根事件，现有引擎优先处理纠错止损。
5. **持续验收**：关注6周期×4指数、买点结构归属、纠错信号/单元双口径、桌面手机端、历史回放日期、行情API及正式域名是否为最新版本。回归脚本：`node macd-resonance/verify.js`、`verify-ledger-history.js`、`verify-ledger-ui.js`（后者需Playwright）。
