## 当前产品口径（2026-11-14）

主图是上证指数、深证成指、创业板指、科创50四张同期K线；周期15/60/90/120分钟、日线和周线。K线密度可通过“− / 根数输入 / +”在15～500根间调节；鼠标可横向拖动或通过日期滚动条浏览所有真实历史。

顶部可切换“四指数看盘”与“逐笔交易复盘”。复盘不是把另外三图收起：**四图始终保留，按所选案例节点的历史日期一起定位**，并分别显示当时的真实价格、MACD及买卖信号。当前案例所属指数的图表用边框高亮。上方可筛选交易轮次、指数及周期，使用上下笔按钮和交易链时间节点快速定位。正常看盘状态有原有关键点位筛选。

**最新页面展示规则（2026-11-14）**：下一根收盘临界价推演只在最新K线、正常看盘且存在已确认钝化重点观察阶段时显示：`watch`（钝化成立、待首次拐头）或`campaign`（已形成买/卖1、结构仍有效、等待后续拐头）。普通中性期、未确认候选钝化、纠错状态、历史拖动及逐笔复盘不显示推演面板或推演虚线，也不出现无价值的占位说明。此调整仅收敛界面展示，MACD信号与既定纠错/止损计算不变。

复盘界面显示**同期MACD信号共振**：以当前选中交易节点为锚点，在各指数同一周期中只考察该历史时刻及**此前两根已完成K线**，统计同向买点或卖点占比，例如“买点同向2/4”。不允许使用之后形成的K线提前确认共振；当前只是可复算的分组信息，尚未验证共振与盈利成功率是否相关。买点、卖点及止损按同一指数同一周期独立处理，不能跨周期拼接交易。

按用户最新明确要求，不增加复盘标签、备注表单或本地存储逻辑。复盘只提供交易链、收益对照和图表定位，保持简洁。波浪分组成功率暂不展开，继续标“波浪周期成功了待验证”。

## 已确认并用于正式统计的交易规则

- EMA12、EMA26和DEA9；MACD柱=2×(DIF−DEA)。
- 严格底／顶钝化：最近两个相邻同色MACD柱区域，中间至少**三根连续非同色柱**；第二同色区域的**最低／最高收盘价**突破前一区域对应收盘价极值，而第二区域**DIF最低／最高值没有突破**前一区域DIF极值。影线不参加突破判断，不能跳过最近相邻的同色区。
- 底钝化后首次DIF向上拐头为买入点，顶钝化后首次DIF向下拐头为卖出点，二次／三次结构按DIF的再拐头记录。
- 普通底部结构在未出现连续三根其他颜色MACD柱前，DIF重新跌破前一区域DIF低点，记为结构失败止损。
- 已完成顶部卖出后，未出现连续三根非红柱，DIF首次严格向上突破前红柱区域参考DIF高点时记为“纠错买回”，且与原始买入轮次关联。未配对的顶部卖点不能生成纠错买回。
- 正式成交配对及成功率使用**底部买入／顶部卖出／普通结构失败止损／纠错买回后独立止损**；同周期买、同周期卖。收益按信号K线收盘价，未扣费用、滑点；不是承诺可以在这一收盘价成交。

### 纠错信号次数与结构单元数量：严格区分

**纠错买回与纠错止损均同时展示“独立触发信号次数 / 参与的结构风险单元数量”**。同一指数/周期同一已完成K线上的一次纠错买回可能重新建立多个与不同旧结构对应的风险单元；同一DIF条件发生一次纠错止损，也可能同时令这些单元逐一退出。市场信号只统计一次，已退出的每个风险单元仍保留独立交易记录与盈亏。

截至2026-11-13的真实日线历史，四个指数共触发 **7次纠错买回、7次纠错止损**，各自关联 **22个买回单元、22个止损单元**。例：上证指数2014-09-12一次纠错买回关联7个结构单元，2014-09-16一次DIF回落触发这7个结构单元止损；不能把一次市场触发显示成7次市场信号。历史点位导航和事件时间线按信号去重；止损明细保留各个结构单元。交易完成笔数和交易胜率仍按单元交易段计算，而非按7次纠错市场信号计算；不能把单元简单收益加总成账户收益，若研究纠错策略本身胜率应另按独立信号分组计算。

### 纠错买回独立止损：正式启用

顶部卖出后合法触发纠错买回时，**锁定该次顶部参考的前一个红柱区域最高 DIF（H）**。纠错买回当根不检查止损，从下一根已完成K线开始，第一次出现 **DIF <= H** 即产生一次正式“纠错止损”并退出该段持仓；必须与原始买入轮次、顶部卖出、纠错买回关联，不能算独立新买点。正常顶部卖出若更早出现则优先完成；同根同时符合止损与顶部卖出只退出一次。纠错止损后原顶部突破的纠错资格结束，不继续无限次买回。该事件独立标在图上、计入交易退出、统计及收益率，**不再存在拟止损、候选止损等假设状态**。

### 独立结构仓位账本（2026-11-14 正式重构）

每个确认的底部买1生成独立的 `B:<K线序号>` 结构ID与风险单元，即便同周期已经持有更老的结构也会新建；同结构买2、买3及其后续上拐仅追加信号，不再新建独立仓位。结构的DIF保护仅在该结构有效期内有效：新结构的失败仅退出其自身单元，不连带旧结构；旧结构被三根反色柱结束，或被下一个已确认底部结构取代后，它的原止损保护不重新激活，余下持仓等待顶部卖点。

一个顶部卖出信号可同时完成多个独立风险单元的退出，因此顶部卖点数量与退出交易数可不相等。此前由顶部合法退出产生的纠错买回，继承对应结构ID，每个重新买回的单元分别适用既定的参考高点DIF独立止损；一个纠错买回信号也可能关联多个原结构单元。

已修复曾记录的上证指数日线案例：**2024-01-16** 新结构买1的参考DIF在 **2024-01-22** 失效，现产生与 `B:8080` 对应的独立 `stopLoss`，而非只产生 `structureFailure`。24个指数/周期真实历史审计通过：底部买1均拥有唯一结构ID；已完成与未完成的风险单元、结构止损、顶部配对互相对账。

**统计口径提示：** 已完成交易段是逻辑风险单元的收盘信号配对（包含纠错再次买入形成的新段），不是已考虑资金分配、同时持仓权重、交易成本、滑点、实际可成交性和盘中触发的完整实盘回测。单元收益率不能加总视作真实账户收益。

### 关键点位口径

| 图上点位 | 程序事件 | 定义 | 是否构成实际进出 |
|---|---|---|---|
| 底 | watchBuy | 底钝化：二区最低收盘创新低、DIF最低值不创新低；同色区间隔至少3根非同色柱 | 否 |
| 顶 | watchSell | 顶钝化：二区最高收盘创新高、DIF最高值不创新高 | 否 |
| 消 | expired / invalid | 钝化结束未拐头或DIF破坏前参考极值 | 否 |
| 买1 | buy | 底钝化成立以后DIF第一次向上拐头 | 买点信号 |
| 买2/买3/买4+ | secondBuy/thirdBuy/laterBuy | 同一底部结构内、未破前区域DIF低点且尚未出现3根反色柱时，再次上拐 | 追加买点，不重复开独立仓位 |
| 卖1/卖2/卖3+ | sell/secondSell/thirdSell/laterSell | 顶部结构首次及后续DIF向下拐头 | 卖点信号，同周期配对 |
| 结构破坏 | structureFailure | 原底部参考低点被DIF跌破、或顶部参考高点被DIF突破 | 技术事件；不等于一定发生实际止损 |
| 止损 | stopLoss | 已持仓且与底部结构匹配的DIF破前参考低点、间隔尚未失效 | 是 |
| 纠错 | correctionBuy | 已真实配对顶部卖出，DIF首次向上突破前红柱区域最高DIF且资格未过期 | 是，与原始买入轮次关联 |
| 纠止 | correctionStop | 纠错买回之后任一已完成K线 DIF <= 锁定H | 是，独立退出 |
| 未配对 | 持仓状态 / 孤立卖点 | 已买未退出，或顶部卖点出现但当时没有可配对持仓 | 否，不虚构成交 |

收益率按信号发生K线的收盘价配对，不包括手续费、滑点和当根收盘后能否成交的可行性。

## 数据来源与历史可用性

所有历史行情必须来源于实际OHLC，不得使用模拟行情。存储位置为：

- data/latest.json：四指数近期指数行情归档，按交易日15分钟增量采集；
- data/history-15.json：从2026-09-24起收集的15分钟真实行情，定时任务持续追加，不删除较早数据；
- data/history-101.json：完整的东方财富历史指数日K线；
- data/history-102.json：将真实日线按自然交易周合成的周K线（不伪称原始周线）。

截至2026-11-13，上证指数日线8763根（1990-12-19起）、深证成指8716根（1991-04-03起）、创业板指3995根（2010-06-01起）、科创50指数1664根（2019-12-31起）。周线从各指数首个可用交易周开始。**15/60/90/120分钟历史仍受行情源限制，不能声称覆盖指数上市以来全部分钟行情。** 四指数对应历史时期不存在时，图上应显示“该时点暂无数据”，不能拿晚近行情填补。

长历史源由api/history.js提供；即时归档由api/latest.js提供。前端仅用已完成K线形成正式信号。

60/90/120分钟的15分钟派生K线使用北京时间固定交易时段。有缺柱时跳过所在组，保留同日其余完整组。60分钟直采与派生合并，同一收盘时点优先取直采。90分钟为90、90和尾段60分钟，120分钟按上午和下午各自完整的两小时聚合。
